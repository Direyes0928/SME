# Nugget AGENT

NUgget Agent is a **personal, source-aware assistant** that helps users understand, recall, and act on *their own information* — notes, documents, and calendar events — without training on the open internet.

This is not a general-purpose chatbot.
This is a **private Subject Matter Expert (SME)** that only knows what you allow it to know.

---

##  What Problem This Solves

People already write:
- Notes
- Word documents
- PDFs
- Meeting details
- Task reminders

But that information becomes **fragmented and forgotten**.

Nugget Agent reconnects:
- Your documents  
- Your calendar  
- Your past notes  

…and surfaces the *right context at the right time*.

---

##  Core Features (Planned)

- Connect to user-approved sources:
  - Local folders
  - SharePoint / OneDrive
  - Notes exports
  - Calendar (read-only)
- Ask natural language questions like:
  - “What should I review before today’s meeting?”
  - “Have I written about this before?”
- Context-aware reminders:
  - Calendar-driven
  - Date mentions inside documents
- Transparent behavior:
  - No hidden actions
  - No autonomous decisions without user approval

---

## Design Principles

- **User-owned data only**
- **Source-grounded responses**
- **No silent automation**
- **Explainable suggestions**
- **Offline-first mindset (future)**

---

## Tech Direction (Initial)

- Frontend: HTML / CSS / JavaScript (static-first)
- Optional backend (later):
  - Vector index for document search
  - Lightweight agent logic
- AI usage:
  - Retrieval-based (RAG-style)
  - No fine-tuning required

---

## MVP Scope (Phase 1)

✔ Load documents from a folder  
✔ Read calendar events  
✔ Ask questions across sources  
✔ Manual refresh / re-index  

No background automation. No notifications yet.

---

## Roadmap (High-Level)

**Phase 1 – Personal Knowledge Reader**  
**Phase 2 – Context Suggestions**  
**Phase 3 – Reminder Intelligence**  
**Phase 4 – Optional Agent Behaviors**

---

##  What This Is NOT

- Not a Copilot replacement
- Not an always-listening assistant
- Not scraping or training on user data
- Not autonomous without consent
